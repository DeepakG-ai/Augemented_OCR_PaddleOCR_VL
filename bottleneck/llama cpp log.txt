One Warning to Address

load_hparams: Qwen-VL models require at minimum 1024 image tokens
              to function correctly on grounding tasks
load_hparams: if you encounter problems with accuracy, try adding
              --image-min-tokens 1024
You're getting 630-690 tokens, below the 1024 threshold. This is fine for text extraction, but if your system uses bounding boxes (bbox fields, spatial memory, field_locations), accuracy may degrade on some pages. Watch for bbox coordinates being slightly off.

If you see bbox issues: change --image-min-tokens 192 → --image-min-tokens 1024. Encoding will go from ~2.5s back to ~5-6s, but bbox accuracy will be protected.
